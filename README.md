# 이유림 | AI / Data

데이터의 특성을 분석하고, 적합한 AI 모델을 적용·검증하는 과정에 관심이 있습니다.  
전자공학 기반의 신호 데이터 분석을 시작으로 시계열 데이터, 머신러닝·딥러닝 모델링까지 경험했으며,  
최근에는 Backend·Database·API까지 개발 범위를 확장하며 AI 기능이 실제 서비스로 연결되는 과정을 경험하고 있습니다.

## 📌 Projects

### 1. Bearing RUL Prediction
**설비 시계열 데이터를 활용한 잔여수명(RUL) 예측**

- 센서 시계열 데이터 EDA 및 전처리
- Rolling Mean, STD, RMS, Trend 기반 Feature Engineering
- Linear Regression, Random Forest, XGBoost 등 모델 비교
- Time-based Split 및 Walk-forward Validation을 통한 시계열 검증
- 모델 성능과 데이터 분포 변화를 분석하여 예측 결과의 한계 및 원인 분석

🔗 [GitHub Repository](https://github.com/yurim6263/bearing_rul_prediction)

---

### 2. Five Weathers
**AI 기반 정찰 UGV 전술적 지휘결심체계 지원시스템**

기상·지형 정보를 활용하여 UGV 임무 수행을 지원하는 AI 기반 의사결정 지원 시스템입니다.

**팀 프로젝트 당시 담당**
- 기상 데이터 전처리
- Random Forest·XGBoost 기반 예측 모델 구축
- 하이퍼파라미터 튜닝 및 성능평가
- UI/UX 설계 및 구현
- 예측 결과 시각화

**프로젝트 이후 개인 확장 진행 중**
- 기존 팀 프로젝트의 Backend·Database 영역까지 개발 범위를 넓혀 개인적으로 재구현하고 있습니다.
- FastAPI·PostgreSQL을 활용한 시스템 구조 및 기능 확장을 진행하고 있습니다.

🔗 [GitHub Repository](https://github.com/yurim6263/UGV_simulation)

### 3. JobFlow
**AI 기반 취업 준비 Web Service**

사용자 데이터를 저장·관리하고 AI 분석 기능과 연결하는 Web Service를 구현했습니다.

- React 기반 Frontend 구현
- FastAPI 기반 Backend 구현
- Database 설계 및 연동
- 사용자 데이터 저장·조회 API 구현
- Database의 사용자 데이터를 AI 분석에 활용할 수 있도록 LLM API 연동
- Frontend → Backend → Database → AI 기능으로 이어지는 서비스 구조 구현

🔗 [GitHub Repository](https://github.com/yurim6263/jobflow)
